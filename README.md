# UncleAI-HTML
HTML ที่เป็น AI ที่เลือกโมเดลได้ 400 กว่าโมเดลโดยใช้ API จาก OpenRouter

ช่วงนี้มีคนถามลุงบ่อยว่า อยากมีหน้าแชทแบบ ChatGPT ไว้ใช้เองในบริษัท ต้องเริ่มยังไง

ลุงเลยทำไฟล์ตัวอย่างมาแจกจ้าาา เป็นไฟล์ HTML ไฟล์เดียว ดับเบิลคลิกเปิดใน Chrome ก็ใช้ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

ข้างในมีสองหน้า หน้าแรกเป็นหน้า "แชท" ทั่วไป เลือกโมเดลได้ว่าจะคุยกับตัวไหน จะเป็น GPT, Claude, Gemini, DeepSeek หรือตัวฟรีก็ได้ เพราะมันต่อผ่าน OpenRouter ซึ่งรวมโมเดลไว้หลายร้อยตัว ตั้ง System prompt ได้ ประวัติแชทเก็บไว้ในเครื่อง

อีกหน้าเป็นหน้า "สร้างรูป (Image Generator)" คัดมาเฉพาะโมเดลที่ทำรูปได้ เลือกสัดส่วนภาพได้ ใส่รูปอ้างอิงให้มันแก้ได้ และบอกด้วยว่ารูปนั้นเสียเงินไปเท่าไหร่ รูปที่ทำเสร็จเก็บไว้ในแกลเลอรี กดโหลดได้

วิธีใช้มีแค่นี้

1. สมัคร OpenRouter แล้วไปสร้าง API Key ที่ [openrouter.ai/keys](https://openrouter.ai/keys)
2. เปิดไฟล์ `my-ai-studio.html` ใน Chrome ในคอมหรือมือถือก็ได้
3. เอาคีย์ไปวางในหน้าตั้งค่า กดทดสอบ แล้วกดบันทึก

ตัวไฟล์ไม่มีค่าใช้จ่ายอะไร ส่วนค่า AI จ่ายให้ OpenRouter ตามที่ใช้จริง ไม่มีรายเดือน ใครยังไม่อยากเติมเงินก็เลือกโมเดลฟรีลองเล่นก่อนได้

ขอเตือนเรื่องเดียว คีย์ของใครของมันนะ อย่าส่งให้คนอื่น เพราะใครได้คีย์ไปก็ใช้เงินในบัญชีเราได้ ตัวไฟล์เก็บคีย์ไว้ในเบราว์เซอร์เครื่องเราเอง โดยไม่ได้ส่งไปไหนนอกจาก OpenRouter
